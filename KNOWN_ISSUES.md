# DRXWNIFY RUST — KNOWN ISSUES & TRACKING (KNOWN_ISSUES.md)

| ID | Компонент | Редакция | Описание проблемы | Влияние | Статус | План решения / Результат |
|---|---|---|---|---|---|---|
| **ISSUE-01** | UI | Mini | Первичное выделение ANGLE буферов в egui-glow достигает ~135 МБ при запуске | Низкое | **Решено** | В релизном профиле с флагами LTO и оптимизацией памяти фактический Working Set в простое стабилизируется на уровне **36.4 МБ**. |
| **ISSUE-02** | UI / Runtime | Full | На устаревших версиях Windows 7/8 без WebView2 Evergreen может потребоваться системный веб-компонент | Низкое | Отслеживается | Поставлять стандартный вебвью-бутстраппер в MSI установщике (Tauri bundle targets). |
| **ISSUE-03** | Audio Engine | Обе | Отсутствие аудиоустройств вывода на беззвучных VPS | Информационное | **Решено** | При ошибке инициализации WASAPI движок плавно переходит в `silent engine mode` без краша приложения. |
