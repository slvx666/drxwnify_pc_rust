# DRXWNIFY MINI — EXPERIMENTAL UI SPECIFICATION (MINI_UI_SPECIFICATION.md)

**Target Application:** Drxwnify Mini (Experimental Edition)  
**Philosophy:** Extreme resource efficiency, instant responsiveness, clean modern aesthetics, zero wasteful computations  
**Layout Principle:** Preservation of the familiar 3-panel architecture, no radical reorganization  
**Themes:** Exactly 6 distinct themes (Night, Day, Gruvbox, Satanic, Sakura Pixel, Linux Terminal)  
**Status:** Canonical Mini Edition UI Design Specification

---

## 1. Архитектурная компоновка (Preserved Layout)

Drxwnify Mini сохраняет привычную для пользователей Drxwnify пространственную организацию элементов:

```
┌────────────────────────────────────────────────────────────────────────┐
│  TOP BAR (Высота: 46px)                                                │
│  [<] [>] [Reload] [ Search: Compact Pill 320px ] [Stats]   [_] [□] [X] │
├───────────────────┬────────────────────────────────┬───────────────────┤
│  LEFT NAV         │  CENTRAL WORKSPACE             │  RIGHT PANEL      │
│  (Library)        │  (Active Screen)               │  (Queue / Lyrics) │
│  Ширина: 220px    │  - Home / Search / Liked /     │  Ширина: 260px    │
│  (Коллапс: 52px)  │    History / Album / Artist /  │  (Скрываемая)     │
│                   │    Downloads / Friends / etc.  │                   │
├───────────────────┴────────────────────────────────┴───────────────────┤
│  PLAYER BAR (Высота: 72px)                                             │
│  [Cover 48px] [Title / Artist] [♡] │ [Shuf][Prev][Play][Next][Rep]     │
│  [Time 0:00 ────●───────── 3:45]   │ [MiniLevels][Vol][Lyrics][Queue]  │
└────────────────────────────────────────────────────────────────────────┘
```

### 1.1. Оптимизация размеров и плотности компонентов
- **Размер окна по умолчанию:** `1200 × 760 px`, минимальный размер: `880 × 580 px`.
- **Top Bar:** Сжата с 56px до **46px**. Кнопки навигации `28×28px`, строка поиска `32px` высотой с быстрым откликом и локальным дебаунсом 150 мс.
- **Left Navigation:** Ширина по умолчанию **220px** (вместо 270px). В свернутом состоянии — **52px** (компактный рейл с пиктограммами).
- **Right Panel:** Ширина **260px** (вместо 310px). Быстрое скрытие по клику на кнопку в плеере.
- **Player Bar:** Высота **72px** (вместо 82–88px). Обложка текущего трека `48×48px`. Компактные кнопки управления `32×32px`.
- **Центральная область:** Увеличенная полезная площадь для вывода списков треков, альбомов и артистов.

## 3. Требования к производительности интерфейса Mini

1. **CPU в простое — 0.0%:**
   - Интерфейс не перерисовывается, если пользователь не взаимодействует с окном и звук остановлен.
   - Во время воспроизведения перерисовывается **только** строка прогресса (раз в 250 мс) и индикатор уровня (раз в 50 мс, если включен).
2. **RAM — до 40 МБ:**
   - Отсутствие дочерних процессов браузерного движка.
   - Виртуализация списков: отображаются только видимые строки (15–20 элементов) независимо от размера плейлиста (хоть 10 000 треков).
   - Ограниченный кэш изображений обложек: LRU кэш на 50 текстур в VRAM с мгновенным освобождением.
3. **Отклик — мгновенный:**
   - Переключение экранов: < 5 мс.
   - Старт приложения: < 80 мс.
