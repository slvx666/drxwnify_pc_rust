## 1. Архитектура компоновки (Layout Architecture)

Приложение построено по классической трёхпанельной десктопной схеме с фиксированной нижней панелью плеера и плавающими модальными окнами.

```
┌────────────────────────────────────────────────────────────────────────┐
│  TOP BAR (Высота: 56px)                                                │
│  [<-] [->] [Refresh] [ Search Pill: 360-480px ] [Decor]   [_] [□] [X]  │
├───────────────────┬────────────────────────────────┬───────────────────┤
│  LEFT PANEL       │  MAIN CONTENT AREA             │  RIGHT PANEL      │
│  (Library / Nav)  │  (Active Screen Scrollable)    │  (NowPlaying/     │
│  Ширина:          │  - Home / Search / Album /     │   Lyrics / Queue) │
│  200px – 420px    │    Artist / Liked / History /  │  Ширина:          │
│  (Коллапс: 64px)  │    Downloads / Friends / etc.  │  280px – 400px    │
│                   │                                │  (Скрываемая)     │
├───────────────────┴────────────────────────────────┴───────────────────┤
│  PLAYER BAR (Фиксированная высота: 82px / 88px для Look.Terminal)      │
│  [Cover 56px] [Title/Artist] [♡] [V] │ [Shuffle][Prev][Play][Next][Rep]│
│  [Time 0:00 ───●────────── 3:45]     │ [LevelMeter][Vol][Bal][Queue/Lyr│
└────────────────────────────────────────────────────────────────────────┘
```

### 1.1. Размеры и отступы основных блоков
- **Окно по умолчанию:** `1360 × 860 px`, минимальный размер: `980 × 640 px`.
- **Top Bar:** Высота `56px`, отступ слева `16px`, отступ справа `16px`. Включает кнопки навигации (размер `36×36px`, иконки `18px`), поле поиска (высота `38px`, скругление `99px` или по стилю Look) и кнопки управления окном.
- **Left Panel (Медиатека):** По умолчанию ширина `270px`. Ресайзится пользователем в диапазоне от `200px` до `420px`. В свернутом состоянии (Collapse) ширина фиксируется на `64px` (отображаются только квадратные иконки разделов).
- **Right Panel (Тексты / Очередь):** По умолчанию ширина `310px` (диапазон `260px` – `450px`). Полностью скрывается кнопками в PlayerBar.
- **Player Bar (Нижняя панель):** Высота `82px` (`88px` для стиля `Terminal`), паддинг `12px 18px`.
  - Обложка текущего трека: `56×56px`, скругление `10px` (или `CircleShape` для стиля `Island`, `0px` для `Terminal`).
  - Центральный блок управления: кнопка Play/Pause `42×42px` (акцентная заливка), кнопки Prev/Next `34×34px`.
  - Слайдер прогресса: высота дорожки `4px` (при наведении `6px`), ползунок `12px`.
  - Блок визуализатора уровней: ширина `64px`, высота `24px`, 32 столбика с промежутком `1px`.

## 3. Стилизация компонентов по 8 типам `Look`

В зависимости от поля `t.look` компоненты интерфейса кардинально меняют поведение и рендеринг:

1. **`Look.Glass` (Татэгаки, Монохром):**
   - Мягкие скругленные углы (`20px`), глубокий Gaussian Blur `28px`.
   - Поле поиска — скругленный pill (`radius: 99px`).
   - Кнопка Play — круглая с акцентным цветом.
2. **`Look.Terminal` (Gruvbox):**
   - Полное отсутствие скруглений (`radius: 0px`), жесткие 2px рамки цвета `#504945`.
   - Вместо стандартного заголовка сверху рендерится **Polybar** — моноширинная панель статуса с цветными блоками модулей (`~/library`, `[album]`, `:: track`).
   - Заголовки секций предваряются двойным двоеточием `:: ${title.toLowerCase()}`.
   - Аватары и обложки — строго прямоугольные без радиусов.
3. **`Look.Neon` (Retrowave):**
   - Рамки `8px` со свечением (Box Shadow `0 0 16px` цвета акцента).
   - Заголовки экранов рендерятся горизонтальным градиентом от белого через акцент в циан.
   - Сверху всего окна накладывается легкая сетка CRT-линий (`Scanlines`, шаг 3px, альфа 0.022).
4. **`Look.Island` (Глубина):**
   - Плавающие островные панели с увеличенным радиусом `24px`.
   - Нижний плеер оформлен в виде парящей капсулы с зеркальным отражением обложки снизу.
   - Мягкие тени с подсветкой акцентного бирюзового цвета.
5. **`Look.Blossom` (Сакура):**
   - Серифные заголовки `Fonts.cormorant` с декоративными японскими субтитрами.
   - Ползунки громкости и прогресса имеют форму лепестка сакуры.
   - В правом верхнем углу окна плавно колышется ветка цветущей вишни.
6. **`Look.Quilt` (Cozy):**
   - Эффект сшитых панелей: рамки рисуются пунктирным швом `dashPathEffect([6px, 6px])`.
   - Карточки альбомов оформлены как снимки Polaroid с легким случайным наклоном (±1.5°).
   - Подзаголовки и пометки оформлены рукописным шрифтом `Fonts.caveat`.
   - Вдоль верхней панели натянута гирлянда с мерцающими разноцветными лампочками.
7. **`Look.Atlas` (Обсерватория):**
   - Оформление старинного звездного атласа: двойные золотые рамки с латунными уголками.
   - Поле поиска оформлено в виде античной нижней линии с подписью шрифтом `Fonts.forum` и разрядкой символов `3px`.
   - Подзаголовки набраны наклонным `Fonts.spectral`.
8. **`Look.Rite` (Satanic):**
   - Острые углы `2px`, готические заостренные ланцетные арки по нижнему краю окна.
   - Заголовки обрамлены символами перевернутых крестов (`CrossMark`) и оккультных сигилов (`Sigil`).
   - Углы панелей снабжены колючими готическими шипами (`gothicCorner`).

## 4. Математика и алгоритмы процедурных фонов (`Backdrops.kt` / `Background.kt`)

### 4.1. Общие правила анимационного цикла
- При активном окне частота шага таймера составляет **30 кадров/с** (`frameMs = 33L`).
- При потере фокуса частота снижается до **12 кадров/с** (`frameMs = 83L`).
- При сворачивании окна в трей или на панель задач (`minimized = true`) анимационный цикл **полностью останавливается**, потребляя **0.0% CPU**.

### 4.2. Алгоритмы 9 процедурных Canvas-бэкдропов

1. **`Mist` (Туманное марево — базовый слой для большинства тем):**
   - Рисует 3 радиальных градиентных пятна, плавно дрейфующих по синусоидальному циклу Пинг-Понг с периодом 42 секунды:
     - Пятно 1: центр `(W * (0.08 + 0.06*k), H * (0.05 + 0.05*k))`, радиус `max(W,H) * 0.42`, альфа `0.55`.
     - Пятно 2: центр `(W * (0.92 - 0.07*k), H * (0.45 + 0.08*k))`, радиус `max(W,H) * 0.38`, альфа `0.45`.
     - Пятно 3: центр `(W * (0.45 + 0.08*k), H * (1.02 - 0.05*k))`, радиус `max(W,H) * 0.40`, альфа `0.42`.

2. **`GlyphField` (Плывущие японские знаки — тема Tategaki):**
   - Сетка глифов с шагом 28px по X и Y (символы катаканы `アイウエオ...`, кандзи `音夜静光風雨空月星波` и цифры).
   - Скорость всплытия: от `3.6` до `10` px/с.
   - Модуляция яркости 2D шумом Перлина: `n = noise(px/260 + t, py/260 - t*0.6) * 0.5 + noise(px/120 - t*0.4, py/120) * 0.25`.
   - Реакция на курсор мыши: в радиусе `160px` от курсора глифы подсвечиваются розовым акцентом `t.glyphAccent`.

3. **`SakuraNightSky` (Сакура — тема Sakura):**
   - 42 лепестка с индивидуальной глубиной `depth ∈ [0..1]`, скоростью падения `14 + 30*depth` px/с, размером `4 + 8*depth` px и фазой качания `sin(time*0.6 + phase) * 40 * depth`.
   - Луна: радиус `19px`, радиальное свечение гало с радиусом `120px` и дыханием `0.16 + 0.04*sin(time*0.5)`.
   - Ветка сакуры: 3 сплайна Безье с 10 цветками (по 5 лепестков на цветок), покачивающаяся на ветру `sway = sin(time*0.35) * 1.2°`.

4. **`StarAtlas` (Звездный атлас — тема Observatory):**
   - 170 звезд с мерцанием `tw = 0.6 + 0.4*sin(time*(0.6 + k*1.6) + phase)`.
   - Небесная сетка с полюсом вращения в `(-160px, -260px)`. Концентрические кольца с шагом `240px` и 12 радиальных лучей, медленно вращающихся со скоростью `time * 0.4°`.
   - Созвездия Лиры и Северной Короны, соединенные золотыми линиями.
   - Падающая звезда (метеор) каждые 14 секунд длительностью `1.2` секунды.

5. **`CozyRoom` (Уютная комната — тема Cozy):**
   - Дышащее радиальное теплое свечение абажура `breathe = 1.0 + 0.12*sin(time*0.4)`.
   - Диагональный плетеный узор ткани под углом 45° с шагом 9px.
   - 26 пылинок, хаотично парящих в луче света с медленным восхождением.
   - Гирлянда лампочек вдоль верхнего края с провисанием `lightY = 3 + sin(x/360 * PI) * 7px` и индивидуальным мерцанием ламп 4 цветов.

6. **`Ash` (Готический пепел и часовня — тема Satanic):**
   - 60 хлопьев пепла, поднимающихся снизу вверх со скоростью `6 + 14*rnd` px/с и горизонтальным дрейфом. Каждый 9-й хлопчик — тлеющий уголек цвета запекшейся крови.
   - Ритуальный круг диаметром `min(W,H)*0.62` с перевернутой пентаграммой и внешним кольцом из 48 рунических штрихов, медленно вращающимся со скоростью `time * 1.2°`.
   - Ряд стрельчатых готических арок вдоль нижнего края окна шириной `120px` и высотой `H * (0.20 + 0.05*((i*7)%3))`.
   - 9 призрачных перевернутых крестов высотой `14–36px`.

7. **`Retro` (Ретровейв — тема Retrowave):**
   - Заходящее неоновое солнце на высоте `0.72*H`, горизонтально нарезанное расширяющимися полосами.
   - Перспективная 3D-сетка горизонта, движущаяся вперед с фазой `(clock / 1.6) % 1.0` (14 горизонтальных полос по квадратичному закону `z*z` и лучи из точки схода).

8. **`Depth` (Океанская глубина — тема Depth):**
   - Вертикальный градиент глубоких бирюзовых тонов.
   - 6 наклонных солнечных лучей, пробивающихся сквозь поверхность воды.
   - 9 каустических пятен у поверхности, колеблющихся по гармоникам синуса.
   - 26 всплывающих пузырей разного радиуса с горизонтальным покачиванием `sin(y/40) * 6px`.

## 5. Полный перечень экранов приложения (12 экранов)

1. **`HomeScreen`:**
   - Персональное приветствие, строка жанровых пилюль (Genres pills).
   - Сетка «Быстрый выбор» (6 карточек 2x3).
   - Секции с горизонтальным скроллом: «Недавние альбомы», «Снова для вас», «Обзоры drxwnslvt».
2. **`SearchScreen`:**
   - Строка ввода с живым автодополнением и историей запросов.
   - Фильтры типов контента: «Все», «Треки», «Альбомы», «Исполнители», «Плейлисты».
   - Список результатов с отображением источника и битрейта.
3. **`LikedScreen`:**
   - Заголовок с градиентным сердцем, счетчиком треков и суммарной длительностью.
   - Кнопка воспроизведения в случайном порядке и сортировка (по дате, названию, артисту).
   - Виртуализированный список треков со статусом загрузки и версией.
4. **`DownloadsScreen`:**
   - Список локально сохраненных треков, папка сохранения, статус активных загрузок с прогресс-барами.
5. **`HistoryScreen`:**
   - Хронологическая лента прослушанных треков с разделителями по дням («Сегодня», «Вчера», даты).
6. **`LocalPlaylistScreen`:**
   - Кастомная обложка, редактирование названия, список треков с возможностью удаления и перетаскивания.
7. **`RemotePlaylistScreen`:**
   - Плейлисты Spotify, Yandex Music, YouTube Music. Информация о создателе, количестве треков.
8. **`AlbumScreen`:**
   - Крупная обложка, год выпуска, лейбл, треклист с номерами дорожек и длительностью.
9. **`ArtistScreen`:**
   - Полноэкранный бандл артиста, кнопка «Подписаться», топ популярных треков, релизы, альбомы («Показать всё»).
10. **`DiscographyScreen`:**
    - Полная дискография выбранного артиста, сгруппированная по альбомам и синглам с полными треклистами.
11. **`ReviewsScreen`:**
    - Лента музыкальных рецензий от `drxwnslvt` с оценками альбомов, текстом обзора и кнопкой прослушивания.
12. **`FriendsScreen`:**
    - Сайдбар со списком друзей (Nostr npub/аватары, статус онлайн, текущий трек с живой позицией).
    - Окно чата ChatHub (история сообщений, стикеры, вложения треков, реакции, статус набора текста).
