## 2. Анализ лицензионной чистоты FFmpeg

Использование FFmpeg требует соблюдения строгих лицензионных правил:

1. **Конфигурация сборки LGPL v2.1+:**
   - ДляDrxwnify требуется **исключительно аудиофункционал**: демуксеры `mov/mp4`, `matroska/webm`, `ogg`, `mp3`, `flac`, `hls` и аудиодекодеры `opus`, `aac`, `mp3`, `flac`, `vorbis`.
   - **Запрещено включать:** `libx264`, `libx265`, `libvpx`, компоненты под лицензией GPL (`--enable-gpl`, `--enable-nonfree`).
   - Флаги сборки:
     ```bash
     ./configure \
       --disable-everything \
       --disable-programs \
       --disable-doc \
       --enable-shared \
       --disable-static \
       --enable-decoder=opus,aac,mp3,flac,vorbis \
       --enable-demuxer=ogg,matroska,mov,mp3,flac,hls \
       --enable-parser=opus,aac,mpegaudio,flac,vorbis \
       --enable-protocol=file,http,https,tcp,tls,crypto \
       --enable-swresample
     ```
2. **Дистрибуция DLL:**
   - В установщик MSI помещаются динамические библиотеки `avcodec-61.dll`, `avformat-61.dll`, `avutil-59.dll`, `swresample-5.dll` (общий размер **~12–14 МБ** против 75 МБ в Kotlin).
   - В дистрибутив и раздел «О программе» включается текст лицензии GNU LGPL v2.1 и ссылка на открытый исходный код сборки FFmpeg.
